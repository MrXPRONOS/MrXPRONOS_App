# Affiches originales CinéX

Déposer ici **les trois fichiers PNG originaux** validés dans le chat « Créer un relais Telegram », sans les modifier ni les convertir :

- `mrx_actu.png` — Actu Foot
- `mrx_live.png` — Pronos Live VIP
- `mrx_jour.png` — Coupons du Jour

Le système utilise exclusivement leurs octets d'origine. Il ne génère aucune image de substitution.
Chaque promotion est envoyée après deux films, avec trois lignes de légende et un bouton vers le canal correspondant.

Si ces fichiers sont absents, l'annonce est différée mais le relais de films reste utilisable.
