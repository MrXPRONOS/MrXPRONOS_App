1. Décompresser ce dossier à la racine du projet.

   - assets/js/main.js
   - service-worker.js
   - pronos.html

   git add assets/js/main.js service-worker.js pronos.html
   git commit -m "Fix affichage des pronostics"
   git push
4. Ouvrir : pronos.html?v=20260806-pronos-fix
5. Faire Ctrl+F5, ou fermer/réouvrir la PWA deux fois.
